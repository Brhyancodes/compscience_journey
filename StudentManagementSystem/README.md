# Student Management System

## Description
This project is a Java Swing GUI application developed for managing student records, course enrollment, and grades.

## Features
- Add students
- Update student information
- Enroll students in courses
- Assign grades
- Dynamic JTable updates
- Error handling using JOptionPane

## Technologies Used
- Java
- Swing
- JTable
- ActionListener
- DefaultTableModel

## How to Run
1. Open the project in IntelliJ or NetBeans
2. Compile all files
3. Run Main.java

## GUI Components Used
- JFrame
- JPanel
- JTable
- JButton
- JTextField
- JComboBox
- JOptionPane

## Event Handling
ActionListeners are used for:
- Adding students
- Updating students
- Enrolling students
- Assigning grades

## Error Handling
The application validates:
- Empty fields
- Invalid age inputs
- Table selection requirements
